# Birthday Wishes V19 — The Envelope Story

A carefully improved version of the V18 birthday website. The 100 birthday wishes, clock opening, background music, fireworks, editor and original special-message/Make a Wish finale are retained.

## What's new

After the **100th wish** and the wheel's normal end celebration:

1. A **closed vintage envelope** arrives in the burgundy scene. The parchment letter is hidden until the envelope is ready.
2. The seal fades and the **upper flap opens**.
3. A visibly **folded note slides upward out of the envelope**.
4. The note **unfolds into textured parchment**.
5. Text appears with the **handwriting-style reveal** while a subtle illustrated hand holding a pen follows along. The default letter is neutral and friendship-appropriate, with **no romantic heart icons**.
6. **Turn the page ↗** begins a reverse journey: the letter folds, slips back inside the envelope, and the flap closes.
7. The envelope **travels toward the “Read the letter again” button** as the original wheel, short special message, and **Make a Wish** button return with extra breathing room.

The previous on-screen “letter unfolding” status text has been removed. Long custom letters scroll inside the paper; the letter and its Turn the page button remain accessible. Small screens receive additional room beneath the wheel and a gently scaled final wheel presentation. There are no extra 100-wish list panels.

## Deploy with GitHub Pages

Extract the ZIP. Put these four files **in the repository root**:

- `index.html`
- `style.css`
- `app.js`
- `birthday-tune.mp3`

Go to GitHub → Settings → Pages, and publish the `main` branch, `/(root)` folder; alternatively use your existing successful Pages workflow. Wait for a successful deploy, then refresh the live site. The HTML uses V19 asset query parameters to minimize stale browser caching.

For testing, use a personalized `?gift=1` link generated by the **Copy link** button on your website's base URL. The plain base URL is the creator/editor view.

## Customize

The base URL lets you set the recipient name, age, optional birthday date, original short message, optional handwritten letter, and signature. If no letter is entered, a friendly ready-made letter is used. The special message and letter are separate; the first appears after the letter closes, and the second appears on parchment.

Wish replies are optional. The Make a Wish button remains visible even without a configured email. For live email delivery, activate and confirm the optional FormSubmit inbox; validation tests do not establish real delivery.

## QA coverage and notes

Checked JavaScript syntax, referenced assets, desktop and phone browser states, envelope-before-paper ordering, folded-letter extraction, unfolding, writing reveal, refolding, replay transition, short-message/button spacing, replay and wish dialog, and 320px-phone long-letter scrolling. Browser sequence tests used **accelerated wish timing in an isolated test copy**. The delivered JavaScript keeps the V18 wheel timing untouched. Real GitHub Pages deployment, email delivery, music autoplay permissions, and every physical phone/browser combination cannot be guaranteed by local tests.

Longer customized letters may need manual scrolling. Accessible reduced-motion users see the message directly without extended cinematic movement.

Personalized links include their text and optional email address in URL query parameters: share only what you're comfortable revealing to the recipient or anyone with that link.
